# cms-flaf.github.io

Landing page for the **FLAF** analysis ecosystem, served at <https://cms-flaf.github.io/>.

It is a single self-contained `index.html` — no build step, no external CSS/JS/fonts — that
introduces FLAF and links to the documentation sites:

| Site | URL |
|---|---|
| FLAF framework | <https://cms-flaf.github.io/FLAF/> |
| HH→bb̄ττ | <https://cms-flaf.github.io/HH_bbtautau/> |
| HH→bb̄WW | <https://cms-flaf.github.io/HH_bbWW/> |
| H→μμ | <https://cms-flaf.github.io/H_mumu/> |

## Editing

Edit `index.html` and push to `main`; GitHub Pages republishes automatically. The page uses only
inline styles and adapts to light/dark via `prefers-color-scheme`.
